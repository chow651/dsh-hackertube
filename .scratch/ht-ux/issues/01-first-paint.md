# 01: 首屏从本地视频库先渲染

**What to build:** 用户打开面板时优先看到本地官方导出或旧缓存中的视频库，远端元信息在后台补齐；缓存过期且网络不可用时仍能浏览旧快照。加载过程有可理解的阶段文案，不再是无信息骨架屏。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 本地导出已就绪、上游列表延迟时，首批视频卡片先出现
- [ ] 缓存过期且上游不可用时，仍展示可浏览的旧列表，并标记为旧数据
- [ ] 骨架屏或加载状态说明当前阶段（导出、元信息同步、评论解析）
- [ ] Host 路由和 Client 渲染测试覆盖先渲染后补齐的行为
