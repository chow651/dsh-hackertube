# 02: 播放失败可见、可兜底、可返回

**What to build:** YouTube 嵌入错误时显示明确错误和「在 YouTube 打开」；用户主动选择时尝试本地直链兜底。打开相关视频后从页面顶部开始，返回列表恢复原滚动位置和筛选；支持 Esc 返回和视频深链。窄屏下相关推荐与 AI 仍可通过明确入口触达。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `yt-error` 或 `api-error` 不再表现为黑屏，用户能看到错误和下一步
- [ ] 有 yt-dlp/ffmpeg 时直链兜底可用；缺失时提示具体依赖
- [ ] 打开相关视频时播放页从顶部开始，返回列表恢复原滚动位置和筛选
- [ ] 支持 Esc 返回，并通过可恢复的地址状态打开同一视频
- [ ] 1100px 宽度下相关推荐和 AI 不需要滑过整段评论才能触达
