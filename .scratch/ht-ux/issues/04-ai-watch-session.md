# 04: AI 观看会话按视频隔离

**What to build:** 每条视频拥有独立的播放位置、AI 消息和字幕窗口；AI 请求带上会话历史和当前播放位置附近的字幕。暂停后的提问仍使用最后的播放位置；无字幕、取字幕超时、cookies 缺失都有明确状态，不假装模型读过字幕。

**Blocked by:** 02 - 播放失败可见、可兜底、可返回

**Status:** ready-for-agent

- [ ] 追问能引用上一条回答
- [ ] 切换视频后 AI 消息清空
- [ ] 暂停一分钟后问「这段在讲什么」仍使用最后的 playhead
- [ ] 有字幕时 prompt 包含带时间戳的字幕片段；无字幕时界面显示仅基于简介
- [ ] 取字幕有上限并显示阶段，不再无反馈卡两分钟
- [ ] 配置 cookies 时使用约定路径，未配置时给出可执行提示
