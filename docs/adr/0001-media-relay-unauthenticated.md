# 中转服务器上暴露免认证的 /media 与 /stream

`dsh-app://` 页面与 DSH 的 webServer 不同源，带不上 cookie，被认证层挡成 401。播放器因此走插件自起的、只监听 `127.0.0.1` 的中转服务器。为了让嵌入被拒时仍有兜底播放，这个服务器额外提供 `/media`（本地缓存）与 `/stream`（yt-dlp + ffmpeg 转封装），两者都不在认证层后面。

已知代价：任何能在本机访问该端口的进程都能拉取这两个地址，取决于 `vid` 是否已知。接受它，因为播放器链路本身已经必须免认证，而端口只绑定回环地址；换来的是嵌入失败时不至于完全无法观看。若要收紧，先给中转服务器加一次性 token，再把 `/embed`、`/media`、`/stream` 一起纳入，而不是只给其中两个加。
