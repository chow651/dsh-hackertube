# 0002: 检索放在 Host 侧，面板与 Agent 共用一条路径

原先面板在浏览器里遍历 6454 条做子串匹配，`hackertube_search` 在 Host 侧另有一套加权与词边界。同一个库、同一个查询给出两种结果，用户和 Agent 对不上。

现在只有一个 `searchLibrary()`：面板请求 `/hackertube/api/search`，工具调用同一个函数。理由不是复用代码，而是两个消费方必须对同一查询给出同一答案，否则「面板里搜不到」和「Agent 说没有」会互相矛盾。

被否决的方案：把 Host 的算法搬进浏览器（6454 条的索引会随每次输入重算，且客户端拿不到 summary / why_hn）；只给工具加中文扩展而保留两套实现（不一致依旧存在）。

状态：accepted
